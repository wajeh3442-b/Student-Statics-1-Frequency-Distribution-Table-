# Frequency Distribution Calculator

## Overview

The Frequency Distribution Calculator is a Java Swing application that converts raw numerical data into an organized frequency distribution table. It provides a graphical user interface for entering data and viewing statistical results.

## Features

* User-friendly Java Swing interface.
* Accepts numerical data entered by the user.
* Calculates class intervals and class boundaries.
* Displays class midpoints and frequencies.
* Calculates total observations and frequency.
* Presents results in a structured table.
* Includes Clear and Generate Frequency Table buttons.

## Technologies Used

* Java
* Java Swing
* JTable and DefaultTableModel
* IntelliJ IDEA

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open `Main.java`.
3. Ensure the public class name matches the filename.
4. Run the `main()` method.
5. Enter numerical values in the input area.
6. Click **Generate Frequency Table** to view the results.

## Example

For the textbook dataset, the program uses seven class intervals with a class width of 0.5 to generate the frequency distribution table.

| Class Interval | Class Boundaries | Midpoint |
| -------------- | ---------------- | -------: |
| 1.5–1.9        | 1.45–1.95        |      1.7 |
| 2.0–2.4        | 1.95–2.45        |      2.2 |
| 2.5–2.9        | 2.45–2.95        |      2.7 |
| 3.0–3.4        | 2.95–3.45        |      3.2 |
| 3.5–3.9        | 3.45–3.95        |      3.7 |
| 4.0–4.4        | 3.95–4.45        |      4.2 |
| 4.5–4.9        | 4.45–4.95        |      4.7 |

The frequency column is calculated from the entered data.

## Purpose

This project demonstrates the practical implementation of frequency distributions in statistics using Java programming and graphical user interface development.
